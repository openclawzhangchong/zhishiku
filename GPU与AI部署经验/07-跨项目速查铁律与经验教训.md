## 一、踩过的坑（吃过哪些亏 / 易失败点汇总）

- **编码**：中文 bat UTF-8+LF → 闪退；`.ps1` 无 BOM → 假语法错误；生成脚本 `%` 模板漏加 `% FMT` → 落盘字面 `%(X)s`；站点 URL `${var}:${port}` 未拆变量 → PS 报“变量引用无效”。
- **沙箱**：命令含 `powershell -NoProfile` 字面量 → 整条被拦且前半段也没执行；`curl -o /dev/null` 返 exit 23 断 `&&` 链；Git Bash `rm` 假报 No such file；`taskkill //F //IM` 参数转换失败；`Remove-Item` 被 safe-delete 拦。
- **网络**：端口没起时全 closed 误判“安全组全封”；临时 TcpListener 只 bind 不 accept 拿 RST 误判“80 被封”；`*.workers.dev` 被污染误判“全断”；Caddy 写 `auto_https off` 全 000。
- **Git**：`git push` 因 `github.com:443` reset 失败；`parents` 写成对象数组 → 422；8 并发 → 403 限流；fork 转私有 422。
- **推理**：用总层数算 KV 高估 4 倍；升级丢 CUDA 运行时 DLL → `0xc0000135`；新包丢 sm_70 PTX；首次慢误判故障；报速度不注温度+场景。

## 二、怎样才能成功（成功做法 / 铁律）

**A. PowerShell 5.1 复用函数**
```powershell
function Invoke-Native {
    param([string]$Exe, [string[]]$Arguments, [string]$ErrFile)
    $prev = $ErrorActionPreference; $ErrorActionPreference = 'Continue'
    try {
        if ($ErrFile) { $out = & $Exe @Arguments 2>$ErrFile } else { $out = & $Exe @Arguments 2>$null }
        $code = $LASTEXITCODE
    } finally { $ErrorActionPreference = $prev }
    return @{ Output = $out; ExitCode = $code }
}
function Wait-ProcessReady { param([string]$ProcessName,[int]$TimeoutSec=40)
    $sw=[Diagnostics.Stopwatch]::StartNew()
    while ($sw.Elapsed.TotalSeconds -lt $TimeoutSec) {
        if (Get-Process -Name $ProcessName -ErrorActionSilentlyContinue) { return $true }
        Start-Sleep -Milliseconds 800
    }; return $false }
}
```

**B. 编码铁律（中文 Windows 必背）**
| 对象 | 规则 |
|---|---|
| `.bat`（中文） | GBK(936) + CRLF；文件名 ASCII；延迟展开下 ASCII `!` 会被吞（写 `[注意]`/`[错误]`） |
| `.ps1` | UTF-8 with BOM + CRLF |
| `%` 模板 | 每个字符串各加一次 `% FMT`，生成后回读校验 |
| URL `${var}:${port}` | 拆中间变量 |
| UTF-8 ↔ GBK | `[IO.File]::WriteAllText($f,[IO.File]::ReadAllText($f,[Text.Encoding]::UTF8),[Text.Encoding]::GetEncoding(936))` |

**C. 沙箱工具链铁律**：`cmd.exe` 禁；`Add-Type` 禁；`ConvertTo-SecureString -AsPlainText` 拦；命令含 `powershell -NoProfile` → 整条拦；命令被拦前半段也没执行 → 整条重跑；curl 落盘再核 `size_download` 且不能写 D 盘；外部 exe 走 `Start-Process -Wait -PassThru -WindowStyle Hidden`；输出 `Set-Content` 到文件再 Read；`Remove-Item` 拦 → 用 `[System.IO.File]::Delete()`。

**D. 网络探测铁律**：端口必须在服务已启动前提下扫；端口结论只能由真实服务给出；`*.workers.dev` 污染 → 用 `*.pages.dev` 反代；Caddy `auto_https disable_redirects` + 站点地址带主机名；绝不写 `auto_https off`。

**E. Git Data API 推送铁律**：空仓库先 `PUT /contents/<file>` 初始化；`parents` = SHA 字符串数组；串行 + `sleep 0.25`；标签已存在 `PATCH /git/refs/tags/{name}` + force；PAT 从 `.tok`/环境变量读，用完删 + 吊销。

**F. llama.cpp / V100 速查**：主包不含 CUDA 运行时 → 回填 `cublas64_12/cublasLt64_12/cudart64_12.dll`；换包前解剖 `ggml-cuda.dll` 确认含 sm_70 PTX；`KV/token(f16) = 全注意力层数 × kv_heads × head_dim × 2 × 2 字节`；启动 bat 必加 `set GGML_CUDA_PDL=0`、`--jinja`、`--api-key`，**不要 `--path webui`**；报速度注温度+场景；首次慢 = PTX JIT 预热（慢在 `listening on` 之后正常）。

## 三、具体怎么实现（实现方式 / 已实测排除项）

- **V100/llama.cpp 已实测排除、勿重复试**：提速无效项 `-b/-ub` 放大、`FORCE_MMQ`、`FORCE_CUBLAS`、`CUDA_GRAPH_OPT`、加线程（零变化）；`DISABLE_FUSION=1` **慢 21%**；`-fa 0` 仅 +0.8%。有效提速唯一手段 = **MTP 投机解码**（`--spec-type draft-mtp --spec-draft-n-max 3`）。
- **V100 速度瓶颈** ≈220 GB/s 有效带宽（峰值 25%）；RTX 3090=100~120 t/s；本机比 SXM2 低 10% 是时钟差，参数补不回。
- **Code 10 真根因** = BIOS 4G+ MMIO 窗口不足（BAR1 需 32GB 连续）；工作组合 = Data Center Driver **551.61** + Above 4G Decoding=Enabled。

## 四、安全提醒（贯穿全库）

- 明文凭据散落：`AUTH_TOKEN`、`sk-v100-...`、ECS 管理员密码、classic PAT `ghp_...` → 用完删 `.tok`、去对应控制台吊销/改密/开 2FA。
- 局域网共享禁删：NTFS ACE 必须**不含 Delete** + `OWNER RIGHTS` 只读 + 移除 `Authenticated Users` 的 Modify（否则禁删形同虚设）。
- 任何对外暴露的推理服务必须加 `--api-key`，否则隧道一开谁都能白用显卡。
